User Guide

How it works

Watch for fillable forms
Let Form Keeper notice forms on pages you visit, so it can offer to save or refill them.
Show a toolbar badge
Put a small dot or count on the extension icon when this page has data to save or fill — click the icon to see it. Turn off for a fully silent icon.
Include sensitive-looking fields
Password fields are never saved, no exceptions. Fields that look like card numbers, CVV, or SSNs are included by default, but you can turn this off to skip them.
Merge Fill (Keep existing inputs)
When filling a form, keep any existing inputs in fields that aren't part of your saved entry instead of clearing them.
Auto-delete old entries
Automatically remove saved forms after a while.
